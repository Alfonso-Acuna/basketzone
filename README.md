# BasketZone

## Descripción del Proyecto

BasketZone es una página web dedicada al baloncesto que cumple con todos los requisitos solicitados. Proporciona información completa sobre este deporte, incluyendo su historia, posiciones, equipamiento, contenido multimedia y más.

## Estructura HTML5

La página utiliza las siguientes etiquetas HTML5 semánticas:

- `<html>` - Estructura raíz del documento
- `<head>` - Metadatos y enlaces
- `<body>` - Contenido visible
- `<header>` - Encabezado de la página
- `<nav>` - Menú de navegación
- `<section>` - Secciones temáticas
- `<article>` - Artículos con contenido
- `<footer>` - Pie de página

## Contenido

El sitio incluye:

- **Texto**: Párrafos (`<p>`), títulos (`<h1>`, `<h2>`, `<h3>`), listas ordenadas (`<ol>`) y no ordenadas (`<ul>`)
- **Imágenes**: Imágenes ilustrativas (`<img>`) de jugadores y canchas de baloncesto
- **Enlaces**: Enlaces internos y externos (`<a>`) hacia Wikipedia y FIBA

## Estilos Básicos con CSS3

Se aplican propiedades básicas:

- `font-family` - Tipografía Arial, Helvetica, sans-serif
- `color` - Colores para texto y elementos
- `background-color` - Colores de fondo
- `margin` - Márgenes externos
- `padding` - Espaciado interno
- `line-height` - Altura de línea

## Botones y Tablas

- **Botones**: `<button>` con eventos onclick para interactividad
- **Tablas**: `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` para mostrar las 5 posiciones del baloncesto con sus funciones

## Multimedia

- **Video**: Elemento `<video>` con controles para reproducir contenido
- **Iframe**: Elemento `<iframe>` para incrustar videos de YouTube
- **Imágenes**: Galería de imágenes relacionadas con el baloncesto

## Estilos Avanzados con CSS3

Se utilizan propiedades avanzadas:

- `border-radius` - Bordes redondeados en elementos
- `box-shadow` - Sombras para dar profundidad
- `transition` - Transiciones suaves en hover
- `transform: scale()` - Efecto de escala en botones
- `position: sticky` - Menú de navegación fijo
- `display: flex/inline-block` - Diseño de elementos

## Secciones del Sitio

1. **Inicio** - Introducción al baloncesto
2. **Historia** - Orígenes e hitos importantes
3. **Posiciones** - Tabla con posiciones, nombres y funciones
4. **Multimedia** - Video y contenido externo
5. **Contacto** - Información de contacto

## Tecnologías Utilizadas

- HTML5
- CSS3
